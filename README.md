# Extension Icons

Win-11 app that keeps track of file extensions and its representation within a Windows 11 environment.

A common problem in Windows environments is that many apps register file extensions as if they owned the format. v.g. a `.htm` is not an HTML document but an Edge document, which is conceptually wrong and it makes some things messy, for example HTML, CSV, XML and other extentions they share the icon of just one of the many applications that can handle them.

The app should recognize many of these common extentions and keep a distinct icon per file-type, regardless of the claiming application. The app could also recognize which apps have capability to handle a given extention, and recognize which installed applications can handle any given file format.

Also, the user could decide, per file-type, which are default extentions for edit, text-edit, browse a file (or other actions)

fix mode will revert all icons and associations to a previous defined status, v.g. after an agressive app has been installed.

themes can allow for sets of file-format icons, includeing themes downdloaded from community repositories online.
